관리 페이지

수정한 내용을 사이트에 반영하는 방법
  1. 이 페이지에서 무기를 추가·수정합니다. 작업 내용은 이 브라우저에 임시로 자동 저장됩니다.
  2. 위의 data.json 저장 버튼을 눌러 파일을 내려받습니다.
  3. GitHub 저장소에서 Add file → Upload files를 눌러 내려받은 data.json을 올리고 Commit changes를 누릅니다. 같은 이름이면 자동으로 덮어씁니다.
  4. 1~2분 뒤 사이트에 반영됩니다.

종류 이름을 바꾸면 해당 종류의 무기도 함께 바뀝니다. 순서는 사이트 메뉴에 표시되는 순서입니다.
